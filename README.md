Bio-HTT Tool

About the Tool:

BioHTT (Bioactivity Prediction for HTT Protein) is a student-developed bioinformatics project that explores the application of machine learning for predicting whether a chemical compound is active or inactive against the Huntingtin (HTT) protein. The tool also calculates important QSAR (Quantitative Structure–Activity Relationship) properties to support compound evaluation.

The application is built using Streamlit, providing a simple and interactive web interface that allows users to perform predictions without requiring programming knowledge.

Users can enter the SMILES notation of a compound, and the application converts it into Morgan fingerprints (ECFP4, 2048 bits) using RDKit. These molecular fingerprints are then processed by a trained Random Forest classification model to predict the compound's activity against the HTT protein.

Features:

1)Predicts whether a compound is Active or Inactive against the Huntingtin (HTT) protein

2)Accepts SMILES notation as input.

3)Generates molecular fingerprints using RDKit.

4)Uses Morgan fingerprints (ECFP4, 2048 bits) as molecular descriptors.

5)Employs a Random Forest machine learning model for classification.

6)Provides prediction confidence scores.

7)Simple and interactive web interface developed with Streamlit.

Workflow:

1)Enter the SMILES notation of a chemical compound.

2)The SMILES string is converted into a molecular fingerprint using RDKit.

3)The trained Random Forest model analyzes the fingerprint.

4)The tool predicts whether the compound is Active or Inactive against the HTT protein.

5) calculating their key QSAR (Quantitative Structure–Activity Relationship) properties

6)The prediction and confidence score are displayed to the user.
